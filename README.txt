ESPEJOS DE NIEBLA
=================

CONTENIDO
---------
index.html                 Página principal
css/styles.css             Estilos responsive
js/script.js               Carga diferida y reproducción
videos/                    Carpeta de archivos audiovisuales

VIDEOS INCLUIDOS
----------------
1. videos/Animación_Águila.mp4
2. videos/Animación_Oso.mp4
3. videos/Animación_Tigrillo.mp4

USO
---
1. Descomprime ESPEJOS_DE_NIEBLA.zip.
2. Conserva la estructura de carpetas tal como está.
3. Abre index.html en un navegador moderno o publica la carpeta completa
   en un servidor web estático (por ejemplo, GitHub Pages).

REPRODUCCIÓN
------------
Los videos están configurados en el orden solicitado, en reproducción
automática, continua (loop), silenciados y sin controles visibles.
Se utiliza playsinline para favorecer la reproducción integrada en móviles.
La carga de cada video comienza cuando se aproxima a la pantalla; una vez
cargado, no se pausa al desplazarse, evitando reinicios innecesarios.

NOTAS
-----
- Los tres videos originales se incluyen en la carpeta videos/.
- No se utilizan frameworks, librerías externas ni dependencias.
- Para reemplazar un video, conserva exactamente su nombre y extensión.
- La reproducción automática depende de las políticas del navegador y del
  dispositivo. El modo muted + playsinline es la configuración compatible
  habitual para permitir autoplay en navegadores móviles.
